# Scripts de Utilidad

Este directorio contiene scripts auxiliares para mantenimiento y desarrollo.

## Archivos:

### `update_article_images.py`
Script para actualizar/migrar imágenes de artículos en la base de datos.

```bash
python scripts/update_article_images.py
```

### `debug_paths.py`
Script de depuración para verificar rutas del sistema de archivos.

```bash
python scripts/debug_paths.py
```

### `verificar_articulos.py`
Script para verificar la integridad de los artículos en la base de datos.

```bash
python scripts/verificar_articulos.py
```

## Uso:
Ejecutar desde el directorio `backend/`:

```bash
python scripts/nombre_del_script.py
```
